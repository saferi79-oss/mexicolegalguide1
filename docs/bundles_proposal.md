## 3. How to Create Bundles in Gumroad (Owner's Guide)
1. **Log in** to your Gumroad Dashboard.
2. Go to **Products** > **New Product**.
3. Select **Digital Product**.
4. **Name:** Enter the Bundle Name (e.g., "Founder's Essential Pack").
5. **Price:** Enter the discounted price (e.g., 79).
6. **Files:** Upload a PDF that contains the links or a ZIP file containing the 3 relevant PDFs.
7. **Description:** Copy and paste the "Gumroad Long Desc" from this document.
8. **Save & Publish.**
9. **Direct Link:** Copy the new product URL for use in your Carrd landing page.
