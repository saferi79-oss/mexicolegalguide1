# Mexico Residency Checklist (Lead Magnet)

This directory contains the source HTML for the "Ultimate Mexico Residency & Visa Checklist (2024)".

## How to generate the PDF
To provide this checklist to your customers as a downloadable PDF:

1. Open `mexico-residency-checklist.html` in any modern web browser (Chrome, Safari, Edge).
2. Press `Ctrl + P` (Windows/Linux) or `Cmd + P` (macOS) to open the Print dialog.
3. Select **"Save as PDF"** as the Destination.
4. Ensure "Background Graphics" is enabled in the settings to preserve the Navy & Gold design.
5. Save the file.

## Distribution
We recommend uploading the generated PDF to **Gumroad** as a $0+ "Pay what you want" product. 
This allows you to capture email addresses and start your automated nurturing sequence.
