# Instagram Automation (Metricool + ManyChat)

This guide helps you set up your discovery and conversion engine.

## 1. Content Scheduling (Metricool)
1. Link your Instagram Business account to Metricool.
2. Use `content-calendar.json` to plan your month.
3. Copy the captions and CTAs from `post-templates.md`.
4. **Link in Bio:** Use Metricool's SmartLinks to create a "Storefront" that mirrors your Instagram feed.

## 2. DM Automation (ManyChat)
Set up the following triggers for your keywords:

| Keyword | Action |
| :--- | :--- |
| **STARTUP** | Send link to Founder's Pack on Gumroad. |
| **SETUP** | Send link to Company Formation Guide. |
| **HIRING** | Send link to Hiring & Contracts Guide. |
| **IP** | Send link to Intellectual Property Guide. |
| **CHECKLIST** | Collect email and send the Free Residency PDF. |

## 3. Engagement
- **Story Mention Trigger:** Automatically reply with "Thanks for the mention! Use code THANKS10 for 10% off any guide" whenever someone tags you.
